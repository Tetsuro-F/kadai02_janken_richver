## ④工夫した点・こだわった点
- じゃんけんを“意味あること”につなげてみました。
- じゃんけんに勝つまで止まらないので、目を瞑って止めることができません。なので二度寝を防げます。
- 勝ったらウザく紙吹雪が舞います。寝起きにはピッタリ。

## ⑤難しかった点・次回トライしたいこと（又は機能）
- アラームが動き出してからのじゃんけん機能の作動や、“勝ち”とアラーム停止の連動など、AIと格闘してコードを書きました。
- アラーム音が乗せられなかったので、それは次回以降チャレンジしたい。
- 見た目がダサいのでそこは心残り。
